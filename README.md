# CSharpVault 🏦

**CSharpVault** is a Windows desktop banking application built with **C#**, **.NET 10**, and **WinForms**, utilizing **SQLite** for relational database storage and transaction management.

---

## 🌟 Key Features

- 👤 **Account & User Management:** User profile dashboard handling balances, account numbers, and user details.
- 💾 **SQLite Persistence:** Relational database integration for storing user credentials, balance updates, and transaction records.
- 💸 **Transactions Engine:** Perform deposits, withdrawals, and balance updates with SQL query operations.
- 🎨 **Modern WinForms UI:** Desktop interface designed for smooth navigation and user interactions.

---

## 🛠️ Tech Stack

- **Language:** C# 13 / .NET 10
- **Framework:** Windows Forms (WinForms)
- **Database Engine:** SQLite (`Microsoft.Data.Sqlite`)
- **IDE:** Visual Studio Code / Visual Studio 2022
